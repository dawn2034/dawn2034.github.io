每日 AI 技术简报｜2026-11-26

今日主线： 推荐召回与排序的统一建模、生成式召回的可证明解码，以及 RL 轨迹的离线复用，正在把过去难以控制的性能收益拆成可测量的机制。Agent 蒸馏和搜索重排尤其值得关注：教师隐藏思维链并不必然阻断策略迁移，增加单步检索质量也可能减少整条轨迹的成本。

归档日期： 2026-11-26（北京时间）。核心观察窗口为 11 月 25 日 07:25:21 至 26 日 07:25:21；扩展窗口为过去 72 小时（11 月 23 日 07:25:21 起），涵盖 arXiv 11 月 25 日展示、24 日 UTC 首次提交的论文及近期模型更新。论文指标除特别说明均为作者报告，未独立复现。

一、推荐与搜索：优先精读

1. LazUnirec：召回、排序共享 Transformer 后如何解决梯度冲突？

发生了什么： 阿里国际团队将召回和排序的用户序列编码统一，通过 LoRA 调制注意力、任务私有与共享 MoE 专家、梯度可靠性估计及排序向召回蒸馏，减少任务间干扰。论文报告 2026 年 10 月一周、10% 流量的线上 A/B：无触发场景订单 +5.75%、GMV +4.01%；有触发场景订单 +4.64%、GMV +3.06%。

为什么重要： 共享序列编码有望减少重复计算，但共享参数会引入多目标冲突。该工作把统一建模与 KV 复用、Kernel Fusion、FP8、跨场景 Batch 一起考虑，适合研究端到端推荐系统。

可信度与局限： 有工业线上实验，比单纯离线指标更有参考价值；但同时替换了原召回与排序模型，无法把总收益归因给某个模块。追踪： 分场景梯度余弦相似度、固定算力消融、P99 延迟、长周期用户价值及独立复现。论文全文

2. SIDECAR：给生成式推荐的 Top-K 增加正确性证书

发生了什么： Etsy 作者提出先用任意候选草稿，再以 Tree Attention 一次评分多个 Semantic ID 路径，计算未探索前缀的概率上界；若证书不成立，则采用 Branch-and-Bound 扩展仍可能影响结果的分支。预算不足时可以输出近似质量界；在论文假设下最坏顺序调用次数不超过 ID 长度。

为什么重要： Beam Search 通常不能告诉系统某次请求是否漏掉高概率商品，证书让动态预算和提前停止有了可解释的依据。局限： 证书保证的是模型分布下的排序精确度，并非用户真实相关性；树注意力并行成本也可能抵消调用次数收益。追踪： 词表冲突、真实目录的前缀分布、候选覆盖率、显存和 P99，特别是低置信度请求。论文全文

3. RecUQ：固定排序再评价不确定性，避免把重排收益当成校准收益

发生了什么： 这篇 TMLR 论文在四个推荐数据集、两个 LLM 主干上，以固定输出排序比较八种不确定性信号。Top10Mass 在多种条件下较擅长检测 Error@10，但长尾优势收窄；受控证据扰动则更适合用排序变化类信号衡量。

为什么重要： 推荐系统的风险监测需要区分排序本身质量、失败预测能力和证据敏感性，不能把一个 AUROC 或 ECE 当作万能指标。局限： 两个主干和有限数据集不能代表所有线上候选分布。追踪： 按活跃度、长尾、冷启动分桶做 risk-coverage 曲线，并比较基于同一排序的监测器。论文 · 评审 · 代码

4. SOARS：让轻量重排器参与 Agent 每一次搜索

发生了什么： 不额外训练的 System One 重排方案联合原始问题和当前子查询，在一次调用中选择长文档片段并对候选重新排序。作者报告 GPT-5.4 Mini 在 BrowseComp-Plus 上准确率从 73.9% 升至 84.7%，搜索次数从 23 降到 14，六个主干在两个基准上均受益。

为什么重要： 单步重排增加开销，但可以通过改善下一步决策减少后续搜索，目标应是整条轨迹的成功率与成本。局限： 基准证据分布、搜索服务和重排器价格影响收益。追踪： 固定候选快照，对比仅子查询、原问题加子查询，以及按不确定性触发的重排策略。论文全文

二、后训练与 Agent

5. RL 的收益能否通过历史 rollout 恢复？

发生了什么： Sheng 等发现直接离线重放原 RL 更新可能崩溃；从同一初始模型出发，按照原生成顺序对归档 rollout 做最大似然训练，却能在研究设定中恢复在线 RL 学习曲线。训练末期少数批次有时也足以恢复最终性能，且不要求区分正确和错误响应。

为什么重要： RL 的昂贵部分可能有相当比例用于搜索更好的采样分布，已获得的轨迹可以成为可复用训练资产。局限： 不能推导出任意离线数据都能替代 RL；同源初始策略、采样分布、时间顺序与任务奖励均关键。追踪： 时间顺序与随机重放、末期轨迹、跨模型迁移、困难样本和完整训练成本。论文全文

6. CoT-Proxy：闭源教师不暴露思维链，也能蒸馏长程策略

发生了什么： 学生以教师工具动作监督训练，思考块留空，用初始学生生成的 replay 数据和 KL 正则限制能力漂移；测试时仍可开启自主推理。开放教师蒸馏使 Qwen3-4B 在 AppWorld 的任务成功率由约 7% 升到 18%，增加推理摘要后达 35%；使用闭源教师可见动作和 API 摘要的版本达 48%，SWE-bench Verified 从约 3% 升到 28%。

为什么重要： 工具调用的策略监督与逐字模仿教师推理可以解耦，适合成本受限的专用 Agent。局限： 教师数据选择、API 许可、训练任务分布和长上下文截断影响结果，闭源教师 SWE-bench 设置仅单种子。追踪： Action-only、摘要、完整 CoT 的等数据等预算比较，以及 OOD 工具调用与通用能力保留。论文全文

7. SAG-Mem 与 Leto：从记忆忠实度转向未来任务效用

发生了什么： SAG-Mem 保留原始对话、不在入库时调用模型，查询时用 BM25 与证据引导词扩展做二次检索；作者报告 LoCoMo 83.08、LongMemEval 80.20。Leto 则通过索引、记忆回放与响应结果反馈选择未来上下文，在 PrefEval 上较最强对照提高 16.3 个百分点。

为什么重要： 两条路线分别降低记忆构建成本和优化记忆对未来决策的贡献，可用于多轮购物需求与偏好撤销。局限： 各自基准和评分协议不同，不应横向比较这些数字；反馈也可能形成错误偏好循环。追踪： 原文可回溯率、时间冲突、检索覆盖、过时信息清理与结果级效用。SAG-Mem · Leto

三、推理与开源模型

8. Draft Calibration：投机解码的收益取决于分布匹配

发生了什么： 研究发现部分公开 Draft 模型虽然能预测最高概率 Token，却相对 Target 分布欠置信；对 Draft 做事后温度缩放，接受长度最高提高约 10%，额外成本很小。

为什么重要： 标准无偏投机采样下，接受概率对应两分布的重叠，即一减全变差距离；仅优化 Top-1 不够。局限： 接受长度增益不等于端到端吞吐增益，且需要使用校准后的 Draft 分布计算接受和拒绝补偿。追踪： 分任务温度、接受率、TPOT、并发负载及分布保持测试。论文

9. GramDelta 与 Shifter Quantization：结构化输出和低比特算子的两个新方向

发生了什么： GramDelta 针对运行时追加语法规则，增量更新历史解析状态并投影精确 Token Mask，作者报告语法首次更新延迟改善 10.7–11.5 倍。Shifter Quantization 通过共享位与移位重建整数操作数，报告在特定 2-bit、4096-token prefill 对照中达到 llama.cpp Q2_K 吞吐的 2.71–3.77 倍。

为什么重要： 动态工具 schema 和低比特矩阵乘法需要独立于模型能力的系统优化。局限： GramDelta 针对追加式更新；量化比较受模型、硬件和 Kernel 影响，KL 改善并不直接保证任务精度。追踪： schema 变化频率、掩码正确性、批量解码速度、实际任务精度和端到端成本。GramDelta · Shifter Quantization

10. ERNIE 5.5 Flash Preview：开放中间 checkpoint 与推理联合设计

发生了什么： 近期公开模型卡显示该 Preview 已提供 Apache 2.0 权重，280B 总参数、14B 激活、1M 上下文，采用 FP4 专家权重、FP8 KV、DSpark 草稿头以及稀疏注意力索引优化。此前已发布 API，因此本期关注权重与部署资料，而非把整个模型当成首次亮相。

为什么重要： 量化感知训练、投机解码与稀疏注意力组合可降低长程 Agent 的计算与缓存成本。局限： 仍是后训练中间版本，模型卡与部分插件 README 的支持状态可能不同步；总权重远非 14B 模型的显存规模。追踪： 固定引擎版本下的 FP4/FP8/BF16 工具调用正确率、不同并发下 DSpark 块长及实际 1M 上下文成本。模型卡 · 官方博客

今日最值得花 30 分钟阅读的一项

Reinforcement Learning Can Be Recovered From Its Own Rollouts。前 10 分钟读离线 RL 重放为什么崩溃；中间 10 分钟读最大似然重放、末期轨迹和顺序消融；最后 10 分钟思考哪些在线采样成本可以转化为可复用数据资产，哪些收益仍依赖奖励探索。不要把结果误解成 SFT 在所有情况下等价于 RL。

今日可立即实践的一件事

实现生成式召回的 Top-K 证书最小实验。 选取 30 个用户历史、一个小型商品目录及冻结的 SID 生成器，枚举全部合法 SID 得到真实模型 Top-K。对比约束 Beam、草稿候选评分和前缀上界驱动扩展；当未探索前缀上界低于第 K 名分数时宣布证书成立。记录证书正确率、Top-K 重叠率、顺序调用次数、显存、P95 和实际 Recall@K。使用故意遗漏高分候选的负控检查证书不会误通过。先在小目录验证正确性，再扩大规模；30 例只用于调试，不足以证明线上性能。
