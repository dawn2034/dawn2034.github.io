01 / 定义与边界

先看学生在哪些前缀上接受监督

LLM 的 on-policy distillation（OPD，同策略蒸馏）以当前学生自己生成的轨迹为学习材料，教师在这些前缀上提供分布、token 分数或语言反馈。核心变化是训练时访问的状态更接近学生推理时实际遇到的状态；它并不由某一种 KL 损失独占定义。GKD 与 MiniLLM 是理解现代 LLM OPD 的两篇核心起点。

需要分开的维度主要选项阅读时问什么
轨迹来源教师 / 当前学生 / 师生混合 / 旧学生缓存谁生成前缀？多久刷新？有无教师介入？
教师与信息独立大模型 / 同模型加特权信息 / 历史检查点 / 黑盒教师教师为何更可靠？推理时学生还能获得哪些信息？
匹配目标Forward KL / Reverse KL / JSD / 一般 f-divergence / 奖励目标优化的是序列分布还是给定状态下的局部条件分布？
反馈粒度全词表 / top-K / 采样 token / 动作 / 轨迹与文字评语保留多少概率质量？估计器偏差与成本如何变化？

本表是编辑整理的比较框架。基础文献：GKD、f-DISTILL、Revisiting OPD、OPD Survey。同一篇论文可能同时跨越多个选项。

02 / 最少必要的公式

“学生采样”与“Reverse KL”是两个决定

设 sₜ = (x, y<ₜ) 为学生已经生成的前缀，pₛ、pₜ 分别为学生与教师在同一前缀上的下一 token 分布。若教师使用额外信息 z，则它实际是 pₜ(· | sₜ, z)。

Llocal(θ) = Es ∼ dπold [ D(pT(· | s), pθ(· | s)) ]
Forward KL = KL(pT ∥ pS)　　Reverse KL = KL(pS ∥ pT)
rt = log pT(yt | st) − log pS(yt | st)

第一行表示把一批 rollout 的状态分布固定后的局部匹配形式；πold 是采样时的学生。第三行是常见的采样 token 对数概率差信号。它不自动等于完整序列 Reverse KL 的全部梯度：状态分布是否求导、是否累计后续奖励、baseline 和 stop-gradient 的位置都会改变估计器。TML 的技术文章采用即时 token 信号；MiniLLM 则从序列目标推导。MiniLLM、OPD+、vOPD；TML 技术文章。

全词表匹配、top-K 匹配和单个采样 token 估计应分别报告。top-K 的归一化、未覆盖质量与特殊 token 处理，也属于算法定义的一部分。跨 tokenizer 时更不能直接按词表索引比较 logits。Revisiting OPD、Byte-Prefix Marginalization。

04 / 应当对读的证据

相同缩写下，结论未必适用同一种训练

问题相互补充或冲突的证据仍需控制的条件
自教师是否需要外部监督？原始 OPSD 使用正确解答等信息；U-OPSD 探索一致性伪解答；RISE 从 RLVR 历史外推教师。无独立教师、无人工标签、无验证器是三种不同条件。
准确率提高是否意味着更强推理？不确定性表达退化、thinking 模型负面结果 与 多样性下降 提醒：短回答和 pass@1 改善可伴随其他能力损失。同时看长推理预算、OOD、pass@k、回退与验证行为；区分普通 OPD 和特权上下文蒸馏。
更多训练问题是否必要？单问题 OPD 侧重状态覆盖；困难样本选择 强调问题难度与长 CoT；稀疏监督 研究少量训练 token。问题数、轨迹数、生成 token、教师评分 token 和反向传播 token 不能互相替代。
教师究竟提供了什么？梯度对齐诊断、教师正确性门控 与 教师噪声及负优势对照 从不同角度检验有效信号。教师正确性、师生兼容、答案信息与更新本身的正则效应需要分开消融。
蒸馏与 RL 应如何组合？广义 OPD、RLSD 探索联合设计；Sequential Beats Joint 在所测数学、逻辑设置中支持先蒸馏后 RL。统一起点、奖励、教师和总预算；不能把一个固定联合配方的失败推广到所有联合优化。

COMPARISON SHEET / 读论文时的记录模板

让后续复现能够公平比较

以下是编辑建议，适合把不同论文转成可比较的实验表。不要依据跨论文排行榜直接判断方法优劣。

  1. 模型与信息：师生 checkpoint、tokenizer、thinking 模式、教师是否看到答案 / 工具结果、是否使用验证器。
  2. 采样与目标：采样温度、轨迹刷新频率、teacher intervention、散度方向、top-K 与残余质量、mask、baseline、stop-gradient。
  3. 总预算：训练问题数、每题 rollout 数、生成 / 打分 / 反传 token、教师和学生 FLOPs、端到端时长、环境调用。
  4. 能力与代价：准确率、pass@k、长度、多样性、校准、OOD、旧能力；是否在相同推理预算下测量。
  5. 能解释机制的基线：原模型、教师序列 SFT、普通 OPD、自蒸馏单独训练、相同预算 RL；其余基线按论文的具体因果主张选择。
